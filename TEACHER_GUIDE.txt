⚡ БЫСТРЫЙ СТАРТ:

   1. Запустить NocoBase:
      NODE_OPTIONS="--max_old_space_size=6144" npm run dev
      
   2. Открыть в браузере:
      http://localhost:13000
      
   3. Следовать инструкциям:
      docs/QUICK_START.md
      
   4. Перезагрузить VS Code:
      Ctrl+Shift+P → Developer: Reload Window
      
   5. Использовать в Copilot Chat:
      @mcp nocobase

🔗 ИСПОЛЬЗУЕМЫЕ ТЕХНОЛОГИИ:

   Frontend:   React 18 + Umi (веб-интерфейс)
   Backend:    Node.js + Koa + TypeScript (REST API)
   Database:   SQLite (файловая БД, не требует установки)
   MCP:        Model Context Protocol + Node.js SDK
   IDE:        VS Code + GitHub Copilot
