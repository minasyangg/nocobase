# 🎓 Система отслеживания учебного процесса - Быстрый старт

## 📋 Что это?

Полнофункциональная система для управления учебным процессом:
- 👨‍🎓 Управление учениками (школьники и частные ученики)
- 📅 Планирование и отслеживание занятий
- 📝 Выдача и контроль домашних заданий
- 📊 Записи оценок и контрольных работ
- 👥 Отчёты для родителей
- 🔗 Интеграция с VS Code через MCP

---

## 🚀 Быстрый старт (5 минут)

### Шаг 1: Запустите NocoBase

```bash
# В терминале (первый раз может занять время)
cd d:/www/nocobase
NODE_OPTIONS="--max_old_space_size=6144" npm run dev
```

Проверьте: **http://localhost:13000** должен открываться

### Шаг 2: Создайте таблицы

Откройте браузер на http://localhost:13000 и следуйте инструкциям из **TEACHER_SYSTEM_SETUP.md** 

Или создайте автоматически (при необходимости):
```bash
node create-tables.js http://localhost:13000 "<your-token>"
```

### Шаг 3: Импортируйте тестовые данные

```bash
# Получите токен из .vscode/mcp.json и запустите:
NOCOBASE_TOKEN="<your-token>" node import-sample-data.js
```

### Шаг 4: Перезагрузите VS Code

- `Ctrl+Shift+P` → `Developer: Reload Window`
- Или просто перезапустите VS Code

### Шаг 5: Используйте MCP в Copilot Chat

Откройте **Copilot Chat** (`Ctrl+Shift+I`):

```
@mcp nocobase

Получи список всех учеников
```

## 🎯 Основные возможности

### 1️⃣ Управление учениками
- Добавить/удалить учеников
- Указать тип обучения (школьник 7/8 класса, частный ученик)
- Хранить контактные данные родителей
- Заметки о каждом ученике

### 2️⃣ Планирование занятий
- Создавать занятия с датой, временем, предметом
- Отмечать тип занятия (урок, консультация, тест)
- Добавлять тему и описание
- Отслеживать статус (запланировано, проведено, отменено)

### 3️⃣ Управление домашними заданиями
- Выдавать ДЗ с описанием и сроком
- Указывать сложность и максимум баллов
- Отслеживать выполнение каждым учеником
- Ставить оценки и комментарии

### 4️⃣ Ведение оценок
- Создавать контрольные работы и тесты
- Вводить баллы/проценты для каждого ученика
- Автоматическая конвертация баллов в оценки (2-5)
- История всех оценок

### 5️⃣ Отчёты
- Средняя оценка по предметам
- Статистика посещаемости
- Анализ выполнения ДЗ
- Рекомендации для родителей

### 6️⃣ MCP интеграция
- Запросы через VS Code Copilot Chat
- Добавление данных прямо из VS Code
- Анализ информации через AI
- Автоматическое создание отчётов

## 💻 Примеры использования

### Использование через веб-интерфейс

1. **Выдать домашнее задание:**
   - Откройте Homeworks
   - Нажмите "+ Add"
   - Заполните детали ДЗ
   - Сохраните

2. **Внести оценку:**
   - Откройте Assessments → создайте контрольную
   - Откройте Assessment Results
   - Добавьте результаты каждого ученика
   - Система автоматически рассчитает оценку

3. **Создать отчёт:**
   - Откройте Reports
   - Нажмите "+ Add"
   - Заполните период, ученика, предмет
   - Добавьте комментарии

### Использование через MCP/Copilot

```
@mcp nocobase

1. Создай домашнее задание "Решить задачи из учебника" по математике на завтра

2. Внеси оценку 85 баллов за контрольную для Ивана Сидорова

3. Получи список всех учеников, которые не выполнили ДЗ

4. Создай отчёт о прогрессе Марии Петровой
```

## ⚙️ Настройка и конфигурация

### Изменить порт

Отредактируйте `.env`:
```
NOCOBASE_API_URL=http://localhost:13000
```

### Изменить БД

По умолчанию используется SQLite (файл-база данных, не требует установки).

Чтобы использовать PostgreSQL, отредактируйте `.env`:
```
DB_DIALECT=postgres
DB_HOST=localhost
DB_PORT=5432
DB_DATABASE=nocobase
DB_USERNAME=postgres
DB_PASSWORD=your_password
```

### Выключить MCP (если не нужен)

Удалите или закомментируйте содержимое `.vscode/mcp.json`

## 🐛 Решение проблем

### Проблема: NocoBase не запускается

**Решение:**
```bash
# Проверьте версию Node
node --version  # Должен быть v18+

# Очистите кэш
rm -rf node_modules package-lock.json

# Переустановите зависимости
npm install --legacy-peer-deps

# Запустите с увеличенной памятью
NODE_OPTIONS="--max_old_space_size=6144" npm run dev
```

### Проблема: Порт 13000 занят

```bash
# Найдите процесс, занимающий порт
netstat -ano | grep 13000

# Убейте процесс (замените PID на номер из вывода выше)
taskkill /PID <PID> /F
```

### Проблема: MCP сервер не подключается в VS Code

**Решение:**
1. Убедитесь, что NocoBase запущен
2. Перезагрузите VS Code: `Ctrl+Shift+P` → "Reload Window"
3. Проверьте, что токен в `.vscode/mcp.json` актуален
4. Посмотрите логи в VS Code Output (View → Output)

### Проблема: Ошибка при создании таблиц

```bash
# Проверьте, что NocoBase полностью загружен
curl http://localhost:13000/api/v1/auth:check

# Если 401 - нужно пройти авторизацию через UI
# Откройте http://localhost:13000 и залогинтесь
```

## 🎓 Рекомендуемый рабочий процесс

## ❓ Часто задаваемые вопросы

**Q: Безопасно ли это использовать для реальных данных учеников?**
A: Да, но убедитесь, что NocoBase защищён паролем (по умолчанию есть). Используйте HTTPS в production.

**Q: Можно ли добавить больше предметов?**
A: Да, просто добавьте новые записи в таблицу Subjects.

**Q: Как экспортировать данные?**
A: NocoBase позволяет экспортировать в CSV/Excel через контекстное меню таблицы.

**Q: Может ли МОЙ AI помощник анализировать прогресс учеников?**
A: Да, через MCP интеграцию - просто попросите в Copilot Chat анализ данных.
