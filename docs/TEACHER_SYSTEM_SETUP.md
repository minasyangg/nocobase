# 📚 Система отслеживания учебного процесса в NocoBase

## Подробное руководство по созданию таблиц и структуры данных

Это руководство поможет вам создать гибкую систему для отслеживания учебного процесса, домашних заданий, оценок и анализа результатов ваших учеников.

---

## 📋 Архитектура системы

Система состоит из 9 основных таблиц:

```
1. ПРЕДМЕТЫ (subjects)
   └─> Список всех предметов (Математика, Физика, Геометрия, Вероятность)

2. КЛАССЫ (classes)
   └─> Школьные классы (7А, 8Б и т.д.)

3. УЧАЩИЕСЯ (students)
   ├─> Связь с классами
   └─> Типы: школьники 7-8 класса + частные ученики

4. ЗАНЯТИЯ/УРОКИ (lessons)
   ├─> Связь с предметами
   ├─> Связь с учащимися
   └─> Различные типы (обычный урок, консультация, тест)

5. ДОМАШНИЕ ЗАДАНИЯ (homeworks)
   ├─> Связь с предметами
   ├─> Описание, срок сдачи
   └─> Максимум баллов

6. ВЫПОЛНЕНИЕ ДЗ (homework_submissions)
   ├─> Связь с ДЗ и учащимися
   ├─> Статус (не начато, в процессе, сдано, проверено)
   └─> Оценка и обратная связь

7. КОНТРОЛЬНЫЕ И ТЕСТЫ (assessments)
   ├─> Связь с предметами
   └─> Типы оценивания (тест, контрольная, самостоятельная)

8. РЕЗУЛЬТАТЫ ОЦЕНОК (assessment_results)
   ├─> Связь с оценками и учащимися
   ├─> Баллы и проценты
   └─> Оценка (2-5)

9. ПОСЕЩАЕМОСТЬ (attendance)
   └─> Отслеживание посещения занятий

10. ОТЧЁТЫ (reports)
    ├─> Периодические отчёты по успеваемости
    └─> Для предоставления родителям
```

## 🚀 Пошаговая инструкция создания в NocoBase

### Шаг 1: Открыть NocoBase

Откройте в браузере: **http://localhost:13000**

### Шаг 2: Создание первой таблицы - ПРЕДМЕТЫ

1. Нажмите **"+ Add Table"** (кнопка внизу слева)
2. Введите название: `subjects`
3. Нажмите создать таблицу

**Добавьте колонки:**

| Название | Тип | Обязательное | Примечание |
|----------|-----|-------------|-----------|
| name | Text | ✅ Да | Название предмета (уникальное) |
| description | Long text | ❌ | Описание предмета |
| color | Color picker | ❌ | Цвет для визуализации |
| icon | Text | ❌ | Эмодзи или иконка (📚, 🔬, 📐, 📊) |

**Образец данных для этой таблицы:**
```
1. Математика | 📚 | #FF6B6B
2. Физика | 🔬 | #4ECDC4
3. Вероятность и статистика | 📊 | #45B7D1
4. Геометрия | 📐 | #96CEB4
```

## 🎨 Рекомендуемые настройки для удобства

### 1. Создайте Views (представления) для разных сценариев

**Для таблицы Lessons:**
- **View 1**: "Запланированные уроки" - отфильтровать status = "planned"
- **View 2**: "Проведённые уроки" - отфильтровать status = "completed"
- **View 3**: "По предметам" - группировать по subject

**Для таблицы Homeworks:**
- **View 1**: "Активные ДЗ" - отфильтровать dueDate >= сегодня
- **View 2**: "Просроченные" - отфильтровать dueDate < сегодня и статус != "completed"

**Для таблицы Students:**
- **View 1**: "Школьники" - отфильтровать studentType = "school"
- **View 2**: "Частные ученики" - отфильтровать studentType = "private"

### 2. Создайте формулы для автоматизации

Примеры полезных вычисляемых полей:

**В assessment_results:**
```
Формула для percentage:
IF({points} > 0, ROUND(({points} / {assessment.maxPoints}) * 100, 2), 0)
```

**В homework_submissions:**
```
Формула для автоматической оценки:
IF({points} >= {homework.maxPoints} * 0.9, 5,
  IF({points} >= {homework.maxPoints} * 0.75, 4,
    IF({points} >= {homework.maxPoints} * 0.6, 3, 2)))
```

## 💡 Примеры использования

### Сценарий 1: Выдача домашнего задания

1. Откройте таблицу **Homeworks**
2. Нажмите **"+ Add"**
3. Заполните:
   - title: "Задачи на движение"
   - description: "Решить задачи 1.1-1.5 из учебника"
   - subject: "Математика"
   - givenDate: "сегодня"
   - dueDate: "на 3 дня позже"
   - maxPoints: "10"

### Сценарий 2: Отслеживание выполнения ДЗ

1. Откройте **Homeworks**
2. Нажмите на ДЗ, кликните на кнопку связи с **homework_submissions**
3. Нажмите **"+ Expand record"** и добавьте:
   - student: "выберите ученика"
   - status: "в процессе / сдано"
   - submittedDate: "дата сдачи"
   - points: "1-10"
   - feedback: "ваш комментарий"

### Сценарий 3: Ввод оценок за контрольную

1. Откройте **Assessments**
2. Нажмите **"+ Add"**
3. Заполните:
   - date: "дата контрольной"
   - subject: "Физика"
   - assessmentType: "Контрольная работа"
   - topic: "Динамика"
   - maxPoints: "100"

4. Откройте созданную контрольную и в связанной таблице **assessment_results** добавьте результаты каждого ученика

### Сценарий 4: Анализ результатов ученика

1. Откройте таблицу **Students**
2. Кликните на ученика
3. Прокрутите вниз - вы увидите все связанные данные:
   - Занятия, которые он посещал (lessons)
   - Выданные ему ДЗ (homework_submissions)
   - Его оценки (assessment_results)

## 📊 Мощные возможности для анализа

### Создание сводных таблиц (Summary View)

1. Откройте любую таблицу
2. Нажмите на кнопку **"+ New View"**
3. Выберите **"Grid"** → затем добавьте **Summary row**
4. Выберите поле для суммирования, например:
   - Среднее значение points в assessment_results
   - Сумма баллов по homework_submissions
   - Количество посещённых занятий

### Создание графиков и диаграмм

1. В правой панели откройте **"Charts"**
2. Выберите тип:
   - **Bar Chart**: Распределение оценок по ученикам
   - **Line Chart**: Прогресс ученика во времени
   - **Pie Chart**: Процент выполнения ДЗ

## 🔗 API для MCP интеграции

После создания таблиц, ваш MCP сервер автоматически создаст инструменты для:

```
GET /api/v1/students - получить список учеников
POST /api/v1/students - создать ученика
GET /api/v1/lessons - получить занятия
POST /api/v1/assessment_results - внести результаты оценок
```

И многие другие операции!
