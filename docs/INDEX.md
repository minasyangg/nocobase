## 🚀 Начать работу (Пошаговая инструкция)

### Этап 1: Запустить NocoBase (⏱️ ~1 минута)

```bash
# В любом терминале
cd d:/www/nocobase
NODE_OPTIONS="--max_old_space_size=6144" npm run dev
```

✅ **Должно открыться:** http://localhost:13000

### Этап 2: Создать таблицы (⏱️ ~10-15 минут)

**Вариант A - Вручную (рекомендуется для обучения):**
1. Откройте http://localhost:13000 в браузере
2. Следуйте инструкциям в **TEACHER_SYSTEM_SETUP.md**
3. Создайте таблицы одну за другой

**Вариант B - Автоматически:**
```bash
# Получите токен из .vscode/mcp.json
# Из файла: "args": [..., "eyJhbGci..."]
# Замените на ваш токен:

NOCOBASE_TOKEN="eyJhbGci..." node create-tables.js
```

### Этап 3: Добавить образцы данных (⏱️ ~2 минуты)

```bash
# Импортирует 5 учеников, 4 предмета, 4 класса и примеры занятий
NOCOBASE_TOKEN="eyJhbGci..." node import-sample-data.js
```

### Этап 4: Перезагрузить VS Code (⏱️ ~30 секунд)

```
Ctrl+Shift+P → "Developer: Reload Window"
```

### Этап 5: Начать использовать! (⏱️ ∞)

Откройте **Copilot Chat** (`Ctrl+Shift+I`):

```
@mcp nocobase

Получи список всех учеников
```

## 🎯 Типичные сценарии использования

### Сценарий 1: Выдача домашнего задания
```
1. Откройте HOMEWORKS
2. Нажмите "+ Add Record"
3. Заполните:
   - Title: "Задачи на площадь"
   - Description: "Решить задачи 5.1-5.7"
   - Subject: "Геометрия"
   - Given Date: сегодня
   - Due Date: +3 дня
   - Max Points: 10
4. Сохраните
```

### Сценарий 2: Запись занятия
```
1. Откройте LESSONS
2. Нажмите "+ Add Record"
3. Заполните:
   - Date: дата занятия
   - Start Time: 15:00
   - Subject: Математика
   - Student: Иван Сидоров
   - Topic: "Графики функций"
   - Status: completed
   - Notes: "Хорошо разобрались с темой"
4. Сохраните
```

### Сценарий 3: Внесение оценок
```
1. Откройте ASSESSMENTS
2. Создайте контрольную:
   - Date: дата контрольной
   - Subject: Физика
   - Assessment Type: control_work
   - Topic: "Электричество"
3. Откройте ASSESSMENT_RESULTS
4. Для каждого ученика:
   - Assessment: выберите контрольную
   - Student: выберите ученика
   - Points: баллы
   - Grade: оценка автоматически
```

### Сценарий 4: Создание отчёта
```
1. Откройте REPORTS
2. Нажмите "+ Add Record"
3. Заполните:
   - Period: "Декабрь 2024"
   - Student: Иван Сидоров
   - Average Grade: 4.2
   - Lessons Attended: 8
   - Lessons Total: 8
   - Homework Completed: 7
   - Homework Total: 8
   - Strengths: "Активный, понимает материал"
   - Areas for Improvement: "Нужна помощь с геометрией"
   - Recommendations: "Заниматься 2 раза в неделю"
```

## 🔧 Техническая информация

### Стек технологий
- **Frontend:** React 18 + Umi
- **Backend:** Node.js + Koa
- **Database:** SQLite (или PostgreSQL/MySQL)
- **MCP:** Node.js MCP Server

### Структура папок
```
d:/www/nocobase/
├── mcp-server-nocobase/
│   ├── src/index.ts              ← Исходный код MCP сервера
│   ├── build/index.js            ← Скомпилированный код
│   └── package.json
├── .vscode/
│   └── mcp.json                  ← Конфиг MCP для VS Code
├── storage/
│   ├── db/nocobase.sqlite        ← База данных SQLite
│   └── logs/
├── .env                          ← Переменные окружения
├── package.json
└── README.md
```

### Порты
- **13000:** Frontend (http://localhost:13000)
- **13001:** Backend API (http://localhost:13001)
- **IPC:** Named pipe (storage/gateway.sock)

### Переменные окружения
```
DB_DIALECT=sqlite                 # Тип БД
DB_STORAGE=storage/db/nocobase.sqlite  # Путь к файлу БД
NOCOBASE_API_URL=http://localhost:13000  # URL сервера
```

## 🐛 Решение проблем

| Проблема | Решение |
|----------|---------|
| NocoBase не запускается | `NODE_OPTIONS="--max_old_space_size=6144" npm run dev` |
| Порт 13000 занят | `taskkill /PID <pid> /F` или используйте другой порт |
| MCP не подключается | Перезагрузите VS Code (Ctrl+Shift+P → Reload Window) |
| Ошибка при импорте данных | Проверьте, что таблицы созданы и токен корректен |
| База данных не инициализирована | `npm run nocobase install` |
