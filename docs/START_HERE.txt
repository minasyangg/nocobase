📊 ТАБЛИЦЫ ДАННЫХ (10 ОСНОВНЫХ)

  1. SUBJECTS (Предметы)
     └─ Математика, Физика, Геометрия, Вероятность

  2. CLASSES (Классы)
     └─ 7А, 7Б, 8А, 8Б

  3. STUDENTS (Учащиеся)
     └─ Связь с классами, контакты, тип обучения

  4. LESSONS (Занятия)
     └─ Дата, время, предмет, ученик, тема, заметки

  5. ATTENDANCE (Посещаемость)
     └─ Статус (присутствовал/отсутствовал/опоздал)

  6. HOMEWORKS (Домашние задания)
     └─ Название, описание, срок, сложность, макс. баллов

  7. HOMEWORK_SUBMISSIONS (Выполнение ДЗ)
     └─ Статус, баллы, оценка, комментарии преподавателя

  8. ASSESSMENTS (Контрольные работы)
     └─ Дата, тип, тема, макс. баллов

  9. ASSESSMENT_RESULTS (Результаты оценок)
     └─ Баллы, процент, оценка, комментарии

 10. REPORTS (Отчёты для родителей)
     └─ Период, ученик, средняя оценка, рекомендации

🚀 БЫСТРЫЙ СТАРТ (3 ШАГА)

  Шаг 1: Запустить NocoBase
  ──────────────────────────
  cd d:/www/nocobase
  NODE_OPTIONS="--max_old_space_size=6144" npm run dev
  
  Проверьте: http://localhost:13000

  Шаг 2: Создать таблицы (выбери один вариант)
  ────────────────────────────────────────────
  Вариант A - Вручную (рекомендуется):
    1. Откройте http://localhost:13000
    2. Следуйте TEACHER_SYSTEM_SETUP.md
    
  Вариант B - Автоматически:
    NOCOBASE_TOKEN="<token-from-.vscode/mcp.json>" node create-tables.js

  Шаг 3: Перезагрузить VS Code
  ─────────────────────────────
  Ctrl+Shift+P → Developer: Reload Window

🐛 РЕШЕНИЕ ПРОБЛЕМ

  Проблема: NocoBase не запускается
  ──────────────────────────────────
  Решение:
    NODE_OPTIONS="--max_old_space_size=6144" npm run dev

  Проблема: Порт 13000 занят
  ──────────────────────────
  Решение:
    taskkill /PID <pid> /F
    (Где <pid> - номер процесса из: netstat -ano | grep 13000)

  Проблема: MCP не подключается в VS Code
  ──────────────────────────────────────
  Решение:
    1. Перезагрузите VS Code (Ctrl+Shift+P → Reload Window)
    2. Убедитесь, что NocoBase запущен
    3. Проверьте токен в .vscode/mcp.json

  Проблема: Ошибка при создании таблиц
  ────────────────────────────────────
  Решение:
    1. Убедитесь NocoBase полностью загружен
    2. Проверьте, что токен корректен
    3. Используйте вариант "вручную" вместо скрипта

📌 ВАЖНЫЕ ЗАМЕЧАНИЯ

  • Все данные хранятся локально в SQLite (storage/db/nocobase.sqlite)
  • NocoBase требует Node.js v18+ (рекомендуется v20+)
  • MCP сервер работает через stdio (stdio-based transport)
  • Токен должен оставаться секретным (не коммитить в git)
  • SQLite хорошо работает для одного пользователя (учителя)
  • Если нужно несколько учителей - используйте PostgreSQL вместо SQLite
