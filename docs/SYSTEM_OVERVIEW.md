# 📚 Система Отслеживания Учебного Процесса - NocoBase Edition

> **Полнофункциональная платформа для управления образовательным процессом: ученики, занятия, домашние задания, оценки и отчёты.**

---

## 🎯 Что это?

Система управления учебным процессом, созданная на основе **NocoBase** - мощной платформы для работы с базами данных. Позволяет учителю отслеживать и анализировать:

✅ **Учеников** - все ученики в одном месте (школьники и частные)
✅ **Занятия** - планирование, отслеживание, описание каждого урока
✅ **Домашние задания** - выдача ДЗ, отслеживание выполнения, оценивание
✅ **Контрольные работы** - ведение оценок и результатов
✅ **Анализ прогресса** - средние оценки, тренды, слабые места
✅ **Отчёты для родителей** - готовые отчёты с рекомендациями

**И всё это доступно прямо из VS Code через MCP интеграцию!**

---

## 🚀 Быстрый старт (5 минут)

### 1️⃣ Запустите NocoBase
```bash
cd d:/www/nocobase
NODE_OPTIONS="--max_old_space_size=6144" npm run dev
```
Откройте: http://localhost:13000

### 2️⃣ Создайте таблицы
Следуйте инструкциям в **TEACHER_SYSTEM_SETUP.md** или запустите:
```bash
NOCOBASE_TOKEN="<token-from-.vscode/mcp.json>" node create-tables.js
```

### 3️⃣ Импортируйте данные
```bash
NOCOBASE_TOKEN="<your-token>" node import-sample-data.js
```

### 4️⃣ Перезагрузите VS Code
`Ctrl+Shift+P` → `Developer: Reload Window`

### 5️⃣ Используйте в Copilot Chat
```
@mcp nocobase

Получи список всех учеников
```

**Готово! ✨**

## 💻 Основные функции

### 1. Управление учениками 👨‍🎓
- Добавить ученика (школьник/частный)
- Указать класс, возраст, контакты
- Добавить заметки и информацию

### 2. Планирование занятий 📅
- Создать занятие с датой, временем, предметом
- Указать тему и описание
- Отмечать статус (запланировано/проведено/отменено)
- Добавить заметки о проведении

### 3. Управление ДЗ 📝
- Выдавать ДЗ с описанием и сроком
- Отслеживать выполнение каждым учеником
- Ставить оценки и комментарии
- Видеть статистику (сдано/не сдано)

### 4. Ведение оценок 📊
- Создавать контрольные работы и тесты
- Вводить баллы для каждого ученика
- Автоматический расчёт оценок
- История всех оценок

### 5. Анализ прогресса 📈
- Средняя оценка по предметам
- Статистика посещаемости
- Анализ выполнения ДЗ
- Рекомендации для улучшения

### 6. Отчёты для родителей 👥
- Создание периодических отчётов
- Анализ сильных и слабых сторон
- Рекомендации для родителей
- Экспорт в PDF/Excel

### 7. MCP интеграция 🤖
- Использование через VS Code Copilot Chat
- Создание записей прямо из IDE
- Анализ данных через AI
- Автоматизация задач

## 📊 Структура данных

**10 основных таблиц:**

```
SUBJECTS (Предметы)
├─ Математика, Физика, Геометрия, Вероятность
│
CLASSES (Классы)
├─ 7А, 7Б, 8А, 8Б
│
STUDENTS (Учащиеся) ←─ CLASSES
├─ Имя, фамилия, тип, email, телефон
│
LESSONS (Занятия) ←─ SUBJECTS, STUDENTS
├─ Дата, время, тема, описание, статус
│
├─ ATTENDANCE (Посещаемость) ←─ LESSONS, STUDENTS
│  └─ Статус присутствия
│
├─ HOMEWORKS (ДЗ) ←─ SUBJECTS
│  └─ HOMEWORK_SUBMISSIONS ←─ HOMEWORKS, STUDENTS
│     └─ Статус, оценка, комментарии
│
└─ ASSESSMENTS (Контрольные) ←─ SUBJECTS
   └─ ASSESSMENT_RESULTS ←─ ASSESSMENTS, STUDENTS
      └─ Баллы, оценка, комментарии

REPORTS (Отчёты) ←─ STUDENTS, SUBJECTS
└─ Средняя оценка, посещаемость, ДЗ, рекомендации
```

## 🔗 Интеграция с VS Code / MCP

После настройки вы можете использовать в **Copilot Chat**:

```
@mcp nocobase

Примеры:
1. "Создай домашнее задание по математике на завтра"
2. "Внеси оценку 85 для Ивана Сидорова за контрольную"
3. "Какие ученики не выполнили ДЗ на эту неделю?"
4. "Создай отчёт о прогрессе Марии Петровой"
5. "Анализируй успеваемость класса 8А"
6. "Сколько часов занятий провёл я в декабре?"
```

MCP сервер автоматически конвертирует эти запросы в REST API вызовы!

## 🛠️ Технический стек

- **Frontend:** React 18 + Umi (UI для работы с данными)
- **Backend:** Node.js + Koa + TypeScript (REST API)
- **Database:** SQLite (файловая БД, не требует установки)
- **MCP:** Model Context Protocol + Node.js SDK
- **IDE Integration:** VS Code + GitHub Copilot

## 📝 Как использовать

### Через веб-интерфейс
```
1. Откройте http://localhost:13000
2. Залогинтесь (по умолчанию есть admin аккаунт)
3. Добавляйте данные через UI
4. Создавайте views и отчёты
```

### Через REST API
```bash
# Получить учеников
curl http://localhost:13000/api/v1/students \
  -H "Authorization: Bearer <token>"

# Создать ДЗ
curl -X POST http://localhost:13000/api/v1/homeworks \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Задачи на движение",
    "subject": "Математика"
  }'
```

### Через MCP / Copilot Chat
```
@mcp nocobase

Просто говорите что нужно сделать на естественном языке!
```

## 🚨 Решение проблем

### NocoBase не запускается?
```bash
NODE_OPTIONS="--max_old_space_size=6144" npm run dev
```

### Порт 13000 занят?
```bash
taskkill /PID <процесс> /F
```

### MCP не подключается?
1. Перезагрузите VS Code (Ctrl+Shift+P → Reload Window)
2. Проверьте, что NocoBase запущен
3. Убедитесь, что токен в `.vscode/mcp.json` правильный
